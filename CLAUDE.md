# Claude Code Project Instructions

Follow the repository's root `AGENTS.md` for the mandatory security rules. Use [`skills/vibecoder-kit/SKILL.md`](skills/vibecoder-kit/SKILL.md) and its product-quality checklist when building or reviewing a website or app.

## Project commands

- `npm test` — run the security scanner's self-tests.
- `npm run security:check` — inspect the staged changes with the configured security patterns.
- `npm run security:setup` — explicitly enable the local Git pre-commit hook.
